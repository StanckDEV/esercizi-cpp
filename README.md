# Esercizi C++

Percorso di studio in C++ seguendo il libro di testo, organizzato per argomento crescente.

## Struttura
- `01-variabili-espressioni` — dichiarazione variabili, cin/cout, operatori, espressioni matematiche
- `02-condizionali` — if/else, operatori logici e di confronto, switch
- `03-cicli` — for, while, do-while, cicli annidati
- `04-programmi-completi` — programmi che integrano più concetti (menu interattivi, ecc.)

## Obiettivo
Consolidare le basi di C++.
