# Esercizi C++

Percorso di studio in C++ seguendo il libro di testo, organizzato per argomento crescente.

## Struttura
- `prima parte:variabili-espressioni` — dichiarazione variabili, cin/cout, operatori, espressioni matematiche
- `seconda parte:condizionali` — if/else, operatori logici e di confronto, switch
- `terza parte:cicli` — for, while, do-while, cicli annidati
- `programmi` — programmi che integrano più concetti (menu interattivi, ecc.)

## Obiettivo
Consolidare le basi di C++.
